## Jira
### MVP:
1. получить задачу;
2. получить подзадачи;
3. получить родительскую задачу;
4. получить комментарии;
5. получить ссылки;
6. поиск задач;
7. получить обязательные поля.
### MVP режим: ТОЛЬКО ЧТЕНИЕ.
### Позднее:
1. создать комментарий;
2. создать баг;
3. создать подзадачу.
### Все операции записи только с обязательным подтверждением.

## Confluence
### MVP:
1. поиск страниц;
2. получение страницы;
3. анализ содержимого;
4. поиск связанных материалов.
### Ограничения:
1. документация не является автоматически источником истины;
2. при конфликте с актуальной задачей конфликт показывается пользователю;
3. потенциально устаревшая документация маркируется, если это можно определить.

## TMS
### MVP:
1. поиск;
2. получение тест-кейса;
3. получение набора;
4. получение тест-плана;
5. чтение метаданных.
### Режим: READ ONLY.
### Следующий этап:
1. create;
2. update.

## GitLab
### MVP:
1. чтение файлов;
2. поиск кода;
3. поиск тестов;
4. чтение MR;
5. чтение статусов pipeline.
### Local write:
1. локальная ветка;
2. создание/изменение файлов;
3. запуск тестов.
### Следующий этап:
1. push;
2. создание MR.
### Запрещено в MVP:
1. push в protected branch;
2. merge;
3. удаление веток;
4. неконтролируемое изменение CI/CD.
