## Jira
### MVP:
1. get issue;
2. get subtasks;
3. get parent;
4. get comments;
5. get links;
6. search issues;
7. get required fields.
### MVP режим: READ ONLY.
### Позднее:
1. create comment;
2. create issue;
3. create subtask.
### Все write-операции — с подтверждением.

## Confluence
### MVP:
1. поиск страниц;
2. получение страницы;
3. анализ содержимого;
4. поиск связанных материалов.
### Ограничения:
1. документация не является автоматически источником истины;
2. при конфликте с актуальной задачей конфликт показывается пользователю;
3. потенциально устаревшая документация маркируется, если это можно определить.

## Testy
### MVP:
1. поиск;
2. получение тест-кейса;
3. получение набора;
4. получение тест-плана;
5. чтение метаданных.
### Режим: READ ONLY.
### Следующий этап:
1. create;
2. update.

## GitLab
### MVP:
1. чтение файлов;
2. поиск кода;
3. поиск тестов;
4. чтение MR;
5. чтение pipeline status.
### Local write:
1. локальная ветка;
2. создание/изменение файлов;
3. запуск тестов.
### Следующий этап:
1. push;
2. создание MR.
### Запрещено в MVP:
1. push в protected branch;
2. merge;
3. удаление веток;
4. неконтролируемое изменение CI/CD.
